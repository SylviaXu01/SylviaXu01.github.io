1. Skills

文件夹形式的指令集合，扩展智能体的能力，给它专门的知识来执行任务

核心特点

  1. 一次构建，多次部署
  2. 技能的名称和描述始终存在于智能体的上下文窗口中，但只有当用户请求与技能描述匹配时，才会加载其余指令

需要的工具

文件系统访问&Bash工具

组合使用

  1. skills+MCP：使用 MCP 从外部源获取数据，然后依靠技能来处理数据或高效检索数据
  2. skills+子智能体：将任务委托给具有隔离上下文的子智能体，子智能体本身也可以使用技能获取专业知识

使用场景

  1. 领域专业知识
  2. 可重复的工作流程
  3. 新能力

What

一种轻量、开放的格式，用于扩展AI agent能力，本质是一个组织好的文件夹，包含以下三类内容：
Ⅰ. 指令
Ⅱ. 脚本
Ⅲ. 资产与资源

How

YAML+md+元数据|指令|资源

组成部分加载规则

  • YAML 前置元数据：名称、描述，总是加载
  • Markdown 正文：输入（漏斗指标（按渠道）、效率指标（按渠道））、输出表格、预算重新分配，触发时加载
  • 资源：按需加载

Skill目录结构

  • SKILL.md：主说明文档，描述 Skill 用途、输入输出、核心流程；通常包含 YAML Frontmatter（元数据区块），以及详细的任务描述、输入输出格式、核心指标和操作流程
  • scripts/：脚本存放目录
  • references/：存放参考规则、模板、辅助文档等

实践建议与最佳实践

  1. 明确 Skill 的输入输出标准，示例文件放在 references 目录
  2. 所有脚本应有异常处理与错误报告能力，便于 Agent 自动修复
  3. 复杂逻辑建议分模块实现，主流程在 SKILL.md 中清晰描述
  4. Excel 公式相关操作建议分离脚本处理，避免直接在 openpyxl 中计算
  5. 尽量输出中间结果与最终数据，便于人工或 Agent 二次校验

Skill作为Agent的武器

核心能力支撑

  • bash：命令行执行能力
  • filesystem：文件系统操作能力

核心价值

为Agent提供上下文与领域专业知识

2.2 基于规则与词典

Jieba 的默认模式：

2.2.1 Log概率与动态规划

问题1：将大量小于 1 的概率值直接相乘，易导致结果趋近于 0，造成浮点数下溢，多条路径之间的差异被缩小，无法比较优劣
→ 数值计算的稳定性

解决方法：jieba 采用了对数概率技术，利用对数函数 log 的性质，将概率的累乘转换为 log 概率的累加。寻找概率最大值就等价于寻找 log 概率之和的最大值。

问题2：暴力计算所有可能路径带来的巨大计算量

解决方法：jieba 引入动态规划的思想。从句子的末尾开始，从后向前递推计算到每个位置的最优切分路径及其 log 概率之和，并记录下来。最终，从句子开头出发，根据记录好的最优路径信息，就能反推出整个句子的最优分词结果。

动态规划要做的就是在句子的每一个位置上，自动比较所有路径，实现在所有可能后续切分中，挑出 log 概率和最大的那条路径。

Tips：

  1. 将结果的量化以加法呈现，累加放大了路径的优劣差异。
  2. 当词数量达到一定程度后，BFA 无法实现功能，用动态规划算法优化。

1.1 NLP概述

NLP：自然语言处理
使计算机理解，解释，生成人类语言，并基于这些能力对文本数据进行决策

NLP = NLU（自然语言理解 输入语言，输出结构化信息）
+ NLG（自然语言生成 输入结构化信息，输出语言）

处理过程层次：
词法分析 -> 句法分析 -> 语义分析 -> 语用分析

主要挑战：
语言的歧义性（词法 结构）
常识与世界知识
深层推理能力
语境与文化
模型幻觉
数据质量与稀缺性
低资源语言
数据偏差（训练数据的偏见）
计算成本
可解释性与安全性
